## EPUB → 本地有声书自动化框架（代号 bookctl）· 架构设计（评审稿）

用户需求：Windows 端、纯 CLI/Cmd 可驱动、大模型友好、支持 MCP 控制；输入 EPUB，本地 GPU 开源 TTS 整本转分章节朗读音频。

- 完成 3 路并行联网调研（TTS 引擎选型 / EPUB+音频工程链路 / CLI+MCP 控制面）+ 2 组检索。
- 产出评审文档：`architecture-epub2audiobook.md`（详细版）与 `architecture-epub2audiobook.html`（可视化评审版，含四层架构图、流水线、选型表、路线图）。
- 核心结论：
  - 默认引擎 CosyVoice 3（Fun-CosyVoice3-0.5B-2512_RL，双 Apache-2.0，中文 CER 0.81%，Win11+3060 6GB 实测）；备选 Qwen3-TTS / VoxCPM2 / GPT-SoVITS；Kokoro 仅作校样。明确排除 XTTS（CPML 非商用且主体注销）、VibeVoice（强制 AI 声明+水印）、Fish S2-Pro 等。
  - 四层架构：L1 控制面（CLI + MCP 共用 handler）→ L2 Job Manager（SQLite、章节级 checkpoint、幂等）→ L3 六 Stage 流水线（ingest/split/normalize/synth/verify/master）→ L4 可插拔引擎层（常驻 daemon，非 SYSTEM 服务，避免 Session 0 拿不到 GPU）。
  - MCP 按 2026-07-28 无状态协议设计，双版本兼容（2025-11-25），显式 job_* tools 为唯一稳定面；Windows stdio 用 UTF-8 二进制写 stdout。
  - 不用 EbookLib（AGPL）做语义切分，自写 zipfile+lxml；WeTextProcessing 中文 TN；ffmpeg 两遍 loudnorm + M4B FFMETADATA；faster-whisper ASR 回验闭环。
- 待用户拍板 6 个决策点（引擎/音色来源/交付形态/ASR 回验范围/Worker 形态/分发方式），确认后进入 P0 技术验证（同章 A/B 盲测）。
