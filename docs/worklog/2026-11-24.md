- 封装：packaging/build-portable.ps1、bookctl.iss（Inno Setup per-user + .epub 关联）、sign.ps1（PFX/指纹/Azure Trusted Signing + RFC3161）、packaging/README.md。
- engine/tts_server.py 重写：新增 --mode sherpa（sherpa-onnx，纯 CPU 真中文语音，自动发现模型目录，num_speakers 音色选择），cosyvoice3 保留适配点；请求级 device/gpu_index/cpu_threads。
- 文档：README 新增 7.2 设备 / 7.3 源 / 7.4 分布式推理结论 / 9 封装；architecture MD 追加附录 B；engine/README 重写；config/sources.example.json。

关键结论（分布式）：开源 TTS 没有能提速的「GPU+CPU 拆分推理」。张量并行需 ≥2 张算力 ≥7.0 的卡（1050 = 6.1 被拒）；device_map 层卸载只解决装不下、比纯 GPU 慢 2-5 倍（即 hybrid）；ORT 单 session 单 EP。故提供三档可选。

实测：solution 0 error（除并行下载锁文件时）；GPU 枚举 = 1 张 GTX 1050 2GB / 16 逻辑核；source list 5 条；UI 两种模式截图确认渲染正常（testdata/ui-simple2.png、ui-detailed.png）。
踩坑：国内直连 GitHub Release 502，必须镜像回退；Grid 不能设 FontFamily（WinUI 非 WPF）；Mcp Program 是 static class，方法必须 static；下载中会锁 CLI bin 目录的 dll 导致编译失败。
