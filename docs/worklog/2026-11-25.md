## 实测补充（发布时踩到的两个坑）

1. **GitHub 会过滤资产名里的非 ASCII 字符**。用中文名上传，无论走 PowerShell+curl.exe、
   Git Bash+curl 还是 Python `http.client`，`?name=` 里 percent-encoded 的中文都会被剥掉，
   变成 `-Mini-0.6.0-setup.exe` / `-.-0.6.0-setup.exe` 这类残域名；改用 `PATCH` 的 JSON body
   改 name 也一样。**结论**：Release 资产统一用 ASCII 名 `BookCtl-*.exe`，中文说明放到
   `PATCH /releases/assets/{id}` 的 `label` 字段（实测 label 完整保留中文）。
   `release-notes-v0.6.0.md` 已写明「下载后的英文文件名 ↔ 本地中文名产物」内容与 SHA-256 对应。
2. **197 MB 上传偶发 `curl (55) Connection was reset`**。第一次是响应阶段断连，
   但 GitHub 其实已经收全（assets 里 size=206,943,055 正确）。脚本已加
   `--retry 3 --retry-delay 2`；遇到报错先查 assets 的 size 再决定是否重传，别盲目重发 197 MB。

最终 Release 资产（v0.6.0，5 个，均为 ASCII 名 + 中文 label）：
`BookCtl-{Mini,Reader}-0.6.0-setup.exe`、`BookCtl-Full-0.3.0-setup.exe`、
`BookCtl-{Mini,Reader}-0.6.0-portable.zip`。
